# layout2

This directory contains a standalone Tailwind-based admin UI prototype for Shopra.

## Structure

- `index.html` — component showcase with layout, buttons, form controls, notifications, data cards, pagination, and state examples.
- `product-edit.html` — a full product creation page rebuilt with a cleaner semantic layout and shared design tokens.
- `assets/styles/tokens.css` — centralized design tokens and a few reusable component styles.

## Notes

- The layout is intentionally independent from the existing Laravel and React code.
- It does not reuse the old layout HTML structure or UIkit classes.
- The design follows the visual language of the existing prototype while using a more scalable structure.
