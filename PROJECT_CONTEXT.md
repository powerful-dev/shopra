# Project Context

Shopra is a SaaS platform for renting ready-made websites.

Customers choose a template, configure content and publish a website.

The public part is rendered using Blade.

The administration panel is built with React.

Backend uses Laravel and PostgreSQL.

The architecture should remain modular and easy to extend.

The long-term goal is to support many website types from a single codebase.

Code quality and maintainability are more important than implementing features as quickly as possible.
